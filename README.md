# TBank

> 把你的知识库变成每天能练的题 —— 本地 JSON 题库、离线练习、答完自动回写统计。

![Flutter](https://img.shields.io/badge/Flutter-3.47.7-02569B?logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-3.13.5-0175C2?logo=dart&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Android-3DDC84?logo=android&logoColor=white)

TBank 是一个用 Flutter 编写的**本地题库练习 App**。题库就是普通的 `.json` 文件，放在手机任意目录即可；App 扫描目录、逐题出题、记录每题累计的作答与答错次数，并在退出时把统计写回原文件。

没有账号、没有网络请求、没有云端同步。你的题目和答题记录只存在于你自己的手机上。

## 为什么用它

- **题库即文件**：不用导入数据库，一个 `.json` 就是一个题库，可以直接用文本编辑器改
- **纯本地**：无服务器、无登录、无埋点，飞行模式下完全可用
- **统计跟着文件走**：每题的作答次数写回 JSON，换设备、传文件都不丢
- **支持配图**：解剖图、电路图、公式截图这类必须看图才能作答的题也能用

## 功能

### 题库管理

- 通过系统目录选择器添加任意多个题库目录
- 自动扫描目录下的 `.json` 文件并列出
- 点击即进入练习，切换题库不会丢失当前进度
- 移除目录只删除配置记录，**不会删除你的任何文件**

### 练习

| 题型 | `type` 值 | 作答方式 |
| --- | --- | --- |
| 单选 | `single_choice` | 选中一项后提交，系统判分 |
| 多选 | `multiple_choice` | 可多选，选项集合完全一致才算对 |
| 判断 | `true_false` | 选中一项后提交，系统判分 |
| 填空 / 简答 | `fill_blank` | 点「展示答案」后自己判断对错 |

- 题目上方实时显示该题的**累计作答次数和答错次数**
- 题目支持**配图**：图片和题库 JSON 放在同一目录，在题目里写文件名即可
  - 选择题的图显示在选项下方，填空/简答题的图紧跟题干
  - 图片缺失或损坏时显示占位框并标出文件名，不影响继续答题
- 判分后立即高亮正确项和你的错选项

### 首页

- 每次启动从内置背景图中随机选一张作为背景
- 圆角毛玻璃打卡卡片，显示连续打卡天数与当天日期
- 点击打卡：文案变为 `HELLO`、日期放大，卡片随后淡出；连续打卡天数按「昨天打过则 +1，断签则重置为 1」计算
- 卡片下方有一张半透明语录卡：启动时随机展示一句，**点一下换一句**（不会连续重复）

### 数据与持久化

- 每题判分后先写入 App 私有目录下的工作副本
- 做完整套、App 进入后台、页面销毁时，把副本回拷到题库所在目录
- 所有配置（题库目录、打卡天数、上次打卡日期）保存在 `config.json`

## 题库格式

### 文件放在哪里

题库就是普通文件夹里的普通 `.json` 文件，放哪儿都行（手机存储、SD 卡、下载目录）。在 App 的「题库管理」里添加这个**文件夹**，它就会列出该目录下所有 `.json`。

```text
我的题库/                     ← 在 App 里添加这一层目录
├── 上皮组织.json             ← 一个题库
├── 上皮组织_Q5.jpg           ← 这张图属于上面那个 JSON
├── 药理学.json
└── 药理学_Q12.png
```

规则：

- 一个 `.json` 就是一个题库，App **不会**把多个文件合并
- **只扫描所选目录的第一层**，子文件夹里的文件不会自动出现，需要单独添加那个子目录
- 配图必须和 `.json` 放在**同一个文件夹**

### 整体结构

```json
{
  "questions": []
}
```

根节点必须是 JSON 对象，所有题目放在 `questions` 数组里，**数组顺序就是出题顺序**。

### 题目字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | 字符串 | 建议 | 题目标识，如 `"Q001"`。重复不会报错，但不利于排查 |
| `type` | 字符串 | ✅ | 只能是下方「四种题型」里的四个值之一 |
| `question` | 字符串 | ✅ | 题干正文 |
| `image` | 字符串 | | 配图文件名。没有图就写 `""` 或省略 |
| `options` | 数组 | 选择题 ✅ | 选项列表。填空/简答题写 `[]` |
| `correctAnswer` | 数组 | ✅ | 正确答案列表，见下方「正确答案怎么写」 |
| `stats` | 对象 | | 作答统计，可以省略 |

`options` 数组里每一项：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `key` | 字符串 | 选项标识，通常是 `A` `B` `C` `D`，必须能和 `correctAnswer` 对上 |
| `text` | 字符串 | 界面上显示的选项文字 |

`stats` 对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `attemptCount` | 整数 | 累计作答次数，由 App 自动累加 |
| `wrongCount` | 整数 | 累计答错次数，由 App 自动累加 |

这两个值自己写 `0` 即可，之后由 App 维护。

### 四种题型

| `type` | 界面表现 | `correctAnswer` 写法 |
| --- | --- | --- |
| `single_choice` | 选一项后提交，自动判分 | 数组，单元素，如 `["B"]` |
| `multiple_choice` | 可多选，选项集合完全一致才算对 | 数组，多元素，如 `["A", "C"]` |
| `true_false` | 选一项后提交，自动判分 | 数组，单元素，如 `["B"]` |
| `fill_blank` | 点「展示答案」，由你自己判断对错 | 数组，如 `["H2O"]` |

### 完整示例

这份可以直接存成 `.json` 使用，五种情况都覆盖了：

```json
{
  "questions": [
    {
      "id": "Q001",
      "type": "single_choice",
      "question": "中国的首都是哪座城市？",
      "image": "",
      "options": [
        { "key": "A", "text": "上海" },
        { "key": "B", "text": "北京" },
        { "key": "C", "text": "广州" },
        { "key": "D", "text": "深圳" }
      ],
      "correctAnswer": ["B"],
      "stats": { "attemptCount": 0, "wrongCount": 0 }
    },
    {
      "id": "Q002",
      "type": "multiple_choice",
      "question": "以下哪些属于编程语言？（多选）",
      "image": "",
      "options": [
        { "key": "A", "text": "Python" },
        { "key": "B", "text": "HTML" },
        { "key": "C", "text": "Java" },
        { "key": "D", "text": "Photoshop" }
      ],
      "correctAnswer": ["A", "C"],
      "stats": { "attemptCount": 0, "wrongCount": 0 }
    },
    {
      "id": "Q003",
      "type": "true_false",
      "question": "地球是太阳系中最大的行星。",
      "options": [
        { "key": "A", "text": "正确" },
        { "key": "B", "text": "错误" }
      ],
      "correctAnswer": ["B"]
    },
    {
      "id": "Q004",
      "type": "single_choice",
      "question": "图中白色圈内的结构是？",
      "image": "q004.jpg",
      "options": [
        { "key": "A", "text": "紧密连接" },
        { "key": "B", "text": "桥粒" },
        { "key": "C", "text": "缝隙连接" }
      ],
      "correctAnswer": ["B"],
      "stats": { "attemptCount": 0, "wrongCount": 0 }
    },
    {
      "id": "Q005",
      "type": "fill_blank",
      "question": "水的化学式是______。",
      "options": [],
      "correctAnswer": ["H2O"]
    }
  ]
}
```

注意 `Q003` 和 `Q005` 都省略了 `stats`、`Q003` 省略了 `image`——这两个字段是可选的。

### 配图怎么放

1. 把图片放进这个 JSON 所在的**同一个文件夹**
2. 在题目里只写**文件名**，不要写路径：

```text
"image": "q004.jpg"          // ✅ 正确
"image": "D:/题库/q004.jpg"  // ❌ 不要写绝对路径
"image": "images/q004.jpg"   // ❌ 不要带子目录
"image": ""                  // ✅ 这道题没有图
```

3. 一道题最多一张图
4. **选择题**的图显示在选项下方；**填空/简答题**的图紧跟题干
5. 图片找不到或无法解码时，界面会显示占位框并标出文件名，不影响继续答题
6. 常见格式都支持（jpg / png / webp / gif），文件名建议保持大小写完全一致

### 正确答案怎么写

**一律用数组**，不按题型区分形态：

| 题型 | `correctAnswer` 写法 |
| --- | --- |
| 单选 | `["B"]` |
| 多选 | `["A", "C"]` |
| 判断 | `["B"]` |
| 填空 / 简答 | `["H2O"]` |
| 填空有多条答案 | `["H2O", "一氧化二氢"]`（界面上分行显示） |

`correctAnswer` 里的每个值都必须能在同一题的 `options[].key` 里找到（填空题的 `options` 为空，不受此约束）。

这样设计是为了**让解析端不必按题型分支**：不管什么题型，正确答案永远是一个字符串列表。

> **兼容说明**：旧题库里写的 `"correctAnswer": "B"` 仍能正常读取，会被当成 `["B"]`；下次做完题保存时会自动转成数组形态。

### 常见错误对照

| 界面现象 | 真实原因 |
| --- | --- |
| 题目变成「展示答案」+ 自判对错 | `type` 拼错了（如 `single`、`radio`、`single-choice`），被静默当成 `fill_blank` |
| 多选只选一个就判对 | `correctAnswer` 里只放了一个元素，漏了其它正确答案 |
| 保存后文件里的答案被改成了数组 | 正常现象：App 统一按数组形态写回 |
| 显示「图片不存在：xxx.jpg」 | 图片没和 JSON 放同一目录，或文件名拼错、大小写不符 |
| 整个题库打不开 | JSON 语法错误，常见于多余/缺失的逗号、中文引号、末尾多写了逗号 |
| 列表里找不到这个题库 | 目录没添加，或 JSON 放在了子文件夹里（只扫第一层） |

### 编辑时的三个注意点

- **必须存成 UTF-8**，否则中文会乱码；用 VS Code 编辑会实时提示语法错误
- **只能用英文引号 `"`**，中文引号 `"` `"` 会让 JSON 解析失败
- **App 保存时会重写整个文件**：顶层除 `questions` 之外的字段（如你自己加的 `"title"`、`"author"`）会丢失，缩进也会统一成 2 个空格

## 隐私

- **不联网**：应用代码里没有任何网络请求（构建期拉依赖除外）
- **不收集数据**：没有统计、没有崩溃上报、没有广告 SDK
- **不申请无关权限**：只有存储权限，用于读写你自己的题库文件

## 常见问题

**扫描不到题库？**
检查两点：目录是否已经添加；「所有文件访问」权限是否已授予。App **只扫描所选目录的第一层**，不会递归子目录。

**统计没有写回原文件？**
写入发生在这几个时机：做完整套题、App 进入后台、离开练习页。如果强制杀进程，最后一次同步可能丢失 —— 但工作副本通常是安全的，下次打开会以源文件为准。

**同名题库冲突？**
工作副本按文件名命名，不同目录下的同名 `.json` 会映射到同一个副本，请避免重名。

**换手机怎么迁移？**
把题库文件夹整体拷过去，在新设备上重新添加目录即可，统计就在 JSON 里。

**点错题库了？**
在「题库管理」里点另一个题库即可切换，当前进度不会丢。

## 已知限制

- 只扫描所选目录的**第一层**，不递归
- 配图始终从题库源目录读取，**不会**随 JSON 复制到 App 私有目录；源目录被删或改名后图片会失效
- 配图高度上限 320px，超长截图会被缩小
- 内置背景图占约 48 MB，是安装包体积的主要来源
- 填空/简答由用户自判，没有自动判分
