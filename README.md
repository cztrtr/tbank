# TBank


![Flutter](https://img.shields.io/badge/Flutter-3.47.7-02569B?logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-3.13.5-0175C2?logo=dart&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Android%20%7C%20Windows-3DDC84?logo=android&logoColor=white)

TBank 是一个用 Flutter 编写的**本地题目练习 App**，支持 Android 与 Windows 桌面。题库就是普通的 `.json` 文件，放在手机或电脑的本地目录即可；App 扫描目录、逐题出题、记录每题累计的作答与答错次数，并自动把统计写回原文件。

没有账号、没有云端同步、没有埋点。除可选的 AI 功能（需要你自己填 DeepSeek API Key）外，全部离线运行。你的题库和答题记录只存在于你自己的手机上。

## 为什么用它

- **题库即文件**：不用导入数据库，一个 `.json` 就是一个题库，可以直接用文本编辑器改
- **纯本地**：无服务器、无登录、无埋点；不启用 AI 功能时飞行模式下完全可用
- **统计跟着文件走**：每题的作答次数写回 JSON，换设备、传文件都不丢
- **支持配图**：解剖图、电路图、公式截图这类必须看图才能作答的题也能用

## 功能

### 快速开始

- 入口在「我的」页顶部的「**快速开始**」按钮
- 内容覆盖八步上手：每日打卡、添加题库、安装插件、开始作答、错题本、配置 DeepSeek API、AI 出题、应用更新
- 文档随包发布，源文件是 `assets/texts/quick_start.md`；以后改说明只改这个文件，不用动代码

### 题库管理

- 通过系统目录选择器添加任意多个题库目录
- 自动扫描目录下的 `.json` 文件，并向下多看**一层子目录**，**按「父文件夹 → 子文件夹 → 题库」三级展示**：同一父目录下添加的多个子文件夹归到一组，父文件夹名在上方、子文件夹名缩进、题库再缩进；子目录里的题库显示为 `子目录/题库名`
- 右上角搜索按钮可按**题库名称**快速筛选
- 添加的多个目录会**并发扫描**，目录多了也不会明显变慢
- 点击即进入练习，切换题库不会丢失当前进度
- 移除目录只删除配置记录，**不会删除你的任何文件**

### 练习

| 题型 | `type` 值 | 作答方式 |
| --- | --- | --- |
| 单选 | `single_choice` | 选中一项后提交，系统判分 |
| 多选 | `multiple_choice` | 可多选，选项集合完全一致才算对 |
| 判断 | `true_false` | 选中一项后提交，系统判分 |
| 填空 / 简答 | `fill_blank` | 输入文字或拍照上传作答图片，由 AI 判分（未配 Key 时手动自判） |

- 题目上方实时显示该题的**累计作答次数和答错次数**
- 题目支持**配图**：图片和题库 JSON 放在同一目录，在题目里写文件名即可
  - 选择题的图显示在选项下方，填空/简答题的图紧跟题干
  - 图片缺失或损坏时显示占位框并标出文件名，不影响继续答题
- 判分后立即高亮正确项和你的错选项
- **支持 LaTeX 数学式**：题干、选项、解析里可以内嵌公式——行内用 `$...$` 或 `\(...\)`，独立公式用 `$$...$$` 或 `\[...\]`，界面会自动渲染排版
- 填空/简答题配置了 DeepSeek 密钥后支持 **AI 判分**：输入文字、拍照/选图，或展开手写区直接手写作答后提交，AI 打 0–10 分，低于 6 分判错
- 内置 standard 插件最下方有「展开手写区」按钮，所有题型都可当草稿；填空/证明题可把手写内容加入作答图片
- 横屏练习时隐藏顶部题库名和底部导航，题目/判分在左、手写板在右；支持触控笔、数位板和鼠标压感
- 任何题型答完后都可以点「**AI 解析**」：选择题让 AI 解释正确答案与各错误选项，填空/解答题让 AI 给出解题步骤并点评你的作答（会把你写的答案和上传的作答图片一起发过去），结果显示在页面最下方；AI 输出的数学式同样用 LaTeX，界面会渲染

### 错题本

- 进入「我的 → 错题本」时自动扫描所有已添加的题库，把**答错过的题**复制到 App 私有目录
- **按「父文件夹 → 题库文件夹 → 错题本」三级展示**：父文件夹由题库目录自动推导，不同文件夹的错题仍互不混合
- 复制时题目题目ID重新编号，并记录来源避免重复收集
- 在「我的 → 设置」里点「**重置错题本**」可以一次性删除所有已有错题本（连同配图）并清空「已删除来源」记录；之后答错的题会按新的初始 3 次计数重新收集，原题库的题目和统计不受影响
- 每道错题有一个计数，初始 **3**：答对减 1、答错加 1，减到 0 记为「已完成」（只对之后新收集的错题生效，已收集的题目保留原计数）
- 题目**不会自动从错题本移除**，列表里按本显示「已完成 / 未完成」和 `已完成数/总数`
- 列表里可以**删除整本错题本**（连同副本里的配图）；删除后这些题不会在下次进入时被自动收集回来，原题库的题目和统计不受影响

### 学习统计

- 入口在「我的」→「学习统计」
- 汇总所有题库的**总题数、总作答次数、总答错次数和整体正确率**
- 按题库文件夹分组展示每个题库的作答次数、答错次数与正确率（带进度条）
- 列出**答错次数最多的前 5 道题**
- 顶部显示连续打卡天数

### AI 出题

- 入口在「我的 → **AI 出题**」，需要先配置 DeepSeek 密钥（见下方 AI 功能章节）
- 输入**主题**（会作为题库文件夹名，如「大学物理学」）和**出题要求 / 知识点**，在出题页选择插件，再勾选该插件声明的题型，选择**题目数量**（5~100），点「生成 N 道题」
- 题型、说明和 `pluginData` schema 都来自插件 manifest；standard 提供单选 / 多选 / 判断 / 填空（含名词解释、解答、证明）
- 生成按题型配额进行，每个已选题型至少 1 道；失败题会优先重试，全部覆盖后才落盘
- 题目按「**每本最多 25 道**」切分保存到 App 私有目录：`Question/<主题>/<主题>-<时间戳>-<批次>.json`，根节点写入 `plugin`，**格式与普通题库完全一致**（可用文本编辑器打开检查）
- 数量超过 25 时会自动分批生成并显示进度（每批 25 道，避免单次输出过长被截断）
- 生成时尽量让选择题的正确答案在 A~E 上随机均匀分布，避免全部集中在某个选项
- 页面下方列出已生成的题库（按主题分组），点开即可练习；答错的题同样会进入错题本
- `Question/` 下的题库也会显示在「管理」页，可以像普通题库一样打开练习
- 网络失败、密钥失效或 AI 返回格式异常时会给出提示，可重试

### AI 变式出题

- 入口在「管理」页每个题库右侧的 ✨ 按钮，针对**已有的 .json 题库**出题
- 流程：读取原题库的题干 / 选项 / 答案 / 解析 → 让 AI **归纳出具体知识点** → 按知识点重新出题（换情景、换数据、换问法，不照抄原题）
- 新题库保存在**原题库所在目录**，文件名按希腊字母递增：`<原文件名>-alpha.json` → `<原文件名>-beta.json` → `<原文件名>-gamma.json`…（24 个字母用完后接数字，如 `-alpha-2`），**不会覆盖已有题库**
- 默认题数与原题库一致（上限 100 道）；题型沿用原题库所属插件声明的题型，都可以在页面上改
- 生成过程分两步显示进度：「归纳知识点」→「按题型配额生成」；归纳出的知识点会列在页面下方
- 新题格式与普通题库完全一致：id 从 `Q001` 重新编号、stats 归零、`image` 字段为空（原题配图不会被复制），根节点沿用原题库的 `plugin`
- 生成完成返回「管理」页会自动刷新，直接点开新题库就能练习；答错的题同样会进入错题本

### 拍书出题

- 入口在「我的」→「拍书出题」
- 拍教材上的**题目**或**知识点讲解**（最多 3 张，支持拍照 / 相册），AI 识别后出题：
  图片是题目时模仿出同类型新题，是知识点时围绕图中内容出题
- 可以填写具体的**出题要求**（如「模仿图中题目出 10 道类似计算题，难度稍高」）
- 可选题型和数量（5~50，每本最多 25 道），题型同样来自所选插件 manifest
- **保存位置可自定义**：`一级目录 / 二级目录 / 文件名`（二级目录和文件名可留空自动生成），
  保存到 App 题库目录 `Question/` 下
- **同名不会覆盖**：同一位置重复生成时，已有文件会保留，新文件自动改成 `<名字>-2`、`<名字>-3`…
- 页面下方列出 `Question/` 里已生成的全部题库，点右侧垃圾桶**二次确认后可彻底删除**（连同变空的子目录），
  已收进错题本的题目不受影响
- 生成完成后到「管理」页刷新即可看到并练习

### 插件系统

- 内置 `standard` 插件处理单选、多选、判断、填空/简答，练习页由 WebView 加载 HTML/JS；
- 设置 → 插件管理支持导入本地 `.zip`、从网络下载、卸载第三方插件；内置插件不可卸载，但 standard 可用更高版本 zip 热更新；
- 一个题库只由一个插件处理，题库根节点写 `"plugin": "coding"`，题目 `type` 使用插件声明的标识；
- 插件可以声明题型名称、AI 出题说明、`pluginData` 的 JSON Schema/示例；
- 插件可通过 `config.html` 提供自己的配置页，配置保存在插件目录的 `config.json`；
- 插件私有数据 `pluginData` 由 App 原样保存，插件可在练习时调用
  `tbankUpdatePluginData` 修改；
- 完整接口、manifest 和示例见 [插件开发指南](docs/PLUGIN_DEVELOPMENT.md)。

### 应用更新

- 入口在「我的」→「设置」→「应用更新」
- 在输入框里填电脑文件服务器的地址（cpolar 链接，只填域名也行），点「下载更新」
- App 会下载 `app-release.apk` 并显示进度；Android 下载完成后自动拉起系统安装界面，桌面端只会保存到本地
- 第一次安装需要按系统提示允许「安装未知应用」


## AI 功能（可选）

AI 能力默认不启用，需要填自己的 DeepSeek API Key。不配也能正常刷题。

### 怎么配置

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册，创建一个 API Key
2. 打开 App → 底部「**我的**」→「**设置**」
3. 在「DeepSeek 密钥」输入框粘贴 Key，点「**保存**」

保存后状态立刻变成「已配置，重新输入可覆盖」。

### 用在哪里

| 功能 | 适用题型 | 说明 |
| --- | --- | --- |
| **AI 判分** | 填空 / 简答 / 插件自定义题型 | 输入文字 / 拍照上传作答图片提交，AI 给 0–10 分，**低于 6 分判错** |
| **AI 解析** | 所有题型 | 答完后点「AI 解析」，AI 解释正确答案与思路；插件题型由插件决定展示方式 |

- 模型固定为 `deepseek-flash`（DeepSeek 当前支持图像理解的模型）
- standard 的 **AI 解析 Prompt 由插件自己构建**；**AI 判分仍由 App 内置 0–10 分评分规则生成并解析**
- 第三方插件可以用 `tbankAiComplete` 自己拼 Prompt，App 只负责鉴权和发送；详细接口见 [插件开发指南](docs/PLUGIN_DEVELOPMENT.md)
- 题目有配图、或你上传了作答图片时，**都会一起发给模型**，所以「看图题」和手写作答也能结合图片判分
- 作答图片 Android 可拍照或从相册选，Windows 直接选文件；一次最多 4 张
- 解析结果显示在页面最下方的独立框里，失败时同一个框里显示原因并可「重试」

### 没配置 / 请求失败怎么办

| 情况 | 行为 |
| --- | --- |
| 没配 Key | 填空题自动退回老流程：点「展示答案」→ 自己判断「答对了 / 答错了」 |
| 请求失败（断网、Key 失效、余额不足） | 弹出提示并退回手动自判，题目仍可继续做 |
| 单选 / 多选 / 判断的自动判分 | **完全不受影响**，本来就是本地比对，不走网络 |

### 费用与数据流向

- 用的是你自己的账号额度，按 token 计费。参考量级：一次带图判分约 400 tokens，一次带作答图片的判分约 600–1500 tokens（图片越多越高），一次带图解析约 500 tokens
- 请求只发往 `https://api.deepseek.com`，不经过任何第三方中转
- 每次只发送当前题目的题干、选项、标准答案、你的作答（文字与作答图片）以及该题配图，不会上传整个题库
- **特别提醒：不要泄露api key给任何人**

## 题库格式

### 文件放在哪里

题库就是普通文件夹里的普通 `.json` 文件，放哪都行。在 App 的「题库管理」里添加这个**文件夹**，它就会列出该目录下所有 `.json`。

```text
我的题库/                     ← 在 App 里添加这一层目录
├── 上皮组织.json             ← 一个题库
├── 上皮组织_Q5.jpg           ← 这张图属于上面那个 JSON
├── 药理学.json
└── 药理学_Q12.png
```

规则：

- 一个 `.json` 就是一个题库，App **不会**把多个文件合并
- **会向下多看一层子目录**：所选目录里的 `.json` 和它直接子目录里的 `.json` 都会列出来（跳过 `.` 开头的隐藏目录）；更深层的文件需要单独添加那个目录
- 配图必须和 `.json` 放在**同一个文件夹**

### 整体结构

```json
{
  "plugin": "standard",
  "pluginVersion": 1,
  "questions": []
}
```

根节点必须是 JSON 对象，所有题目放在 `questions` 数组里，数组顺序就是出题顺序。

- `plugin`：处理这份题库的插件 id；省略时按 `standard` 处理；
- `pluginVersion`：插件协议版本，省略按 1；
- 一个题库只能由一个插件处理，题目里不写 plugin；
- 第三方插件题库必须写对应的 `plugin`，并先安装该插件。

### 题目字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | 字符串 | 建议 | 题目标识，如 `"Q001"`。重复不会报错，但不利于排查。**启动 App 时（以及添加题库目录时）会被 App 自动替换成 `q_` 开头的稳定随机 id 并写回文件，进入错题本页时再兜底检查**，用于与文件位置无关的错题去重 |
| `type` | 字符串 | ✅ | standard 题库为 `single_choice` / `multiple_choice` / `true_false` / `fill_blank`；第三方插件题库使用 manifest 里声明的题型 id |
| `question` | 字符串 | ✅ | 题干正文 |
| `image` | 字符串 | | 配图文件名。没有图就写 `""` 或省略 |
| `options` | 数组 | 选择题 ✅ | 选项列表。填空/简答题写 `[]` |
| `correctAnswer` | 数组 | ✅ | 正确答案列表，见下方「正确答案怎么写」 |
| `analysis` | 字符串 | | 题目解析。作答后显示在判分结果下方，没有就写 `""` 或省略 |
| `stats` | 对象 | | 作答统计，可以省略 |
| `pluginData` | 对象 | | 插件私有数据；standard 不需要，第三方按插件 schema 写入 |

`options` 数组里每一项：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `key` | 字符串 | 选项标识，通常是 `A` `B` `C` `D`，必须能和 `correctAnswer` 对上 |
| `text` | 字符串 | 界面上显示的选项文字 |

`stats` 对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `attemptCount` | 整数 | 累计作答次数，由 App 自动累加 |
| `wrongCount` | 整数 | 累计答错次数，由 App 自动累加 |

这两个值自己写 `0` 即可，之后由 App 维护。

### standard 的四种题型

| `type` | 界面表现 | `correctAnswer` 写法 |
| --- | --- | --- |
| `single_choice` | 选一项后提交，自动判分 | 数组，单元素，如 `["B"]` |
| `multiple_choice` | 可多选，选项集合完全一致才算对 | 数组，多元素，如 `["A", "C"]` |
| `true_false` | 选一项后提交，自动判分 | 数组，单元素，如 `["B"]` |
| `fill_blank` | 点「展示答案」，由你自己判断对错 | 数组，如 `["H2O"]` |

第三方插件可以声明自己的 `type`，例如 `coding`；具体字段含义由插件的
`typeDescriptions` / `typeSchemas` 定义，题目私有字段放 `pluginData`。

### 配图怎么放

1. 把图片放进这个 JSON 所在的**同一个文件夹**
2. 在题目里只写**文件名**，不要写路径：

```text
"image": "q004.jpg"          // ✅ 正确
"image": "D:/题库/q004.jpg"  // ❌ 不要写绝对路径
"image": "images/q004.jpg"   // ❌ 不要带子目录
"image": ""                  // ✅ 这道题没有图
```

3. 一道题最多一张图
4. **选择题**的图显示在选项下方；**填空/简答题**的图紧跟题干
5. 图片找不到或无法解码时，界面会显示占位框并标出文件名，不影响继续答题
6. 常见格式都支持（jpg / png / webp / gif），文件名建议保持大小写完全一致

### 正确答案怎么写

**一律用数组**，不按题型区分形态：

| 题型 | `correctAnswer` 写法 |
| --- | --- |
| 单选 | `["B"]` |
| 多选 | `["A", "C"]` |
| 判断 | `["B"]` |
| 填空 / 简答 | `["H2O"]` |
| 填空有多条答案 | `["H2O", "一氧化二氢"]`（界面上分行显示） |

`correctAnswer` 里的每个值都必须能在同一题的 `options[].key` 里找到（填空题的 `options` 为空，不受此约束）。

这样设计是为了**让解析端不必按题型分支**：不管什么题型，正确答案永远是一个字符串列表。

### 解析怎么写

`analysis` 是纯文本，答完题后显示在**判分结果下方**——无论答对还是答错都会展示。

```json
"analysis": "北京是中华人民共和国的首都；上海、广州、深圳都是重要的中心城市，但不是首都。"
```

- 支持换行：JSON 里写成转义符 `\n`
- 留空或省略时**不显示**解析框，界面上不会出现空框
- 与答案对错无关，只要作答完成就展示

### 数学式怎么写

题干、选项、解析、正确答案里都可以内嵌 LaTeX 公式，App 会自动渲染排版：

| 类型 | 分隔符 | 示例 |
| --- | --- | --- |
| 行内公式 | `$...$` 或 `\(...\)` | `已知 $x^2+1=0$，则…` |
| 独立公式 | `$$...$$` 或 `\[...\]` | `$$\frac{a}{b} = \sqrt{c}$$` |

- 公式写在 JSON 字符串里时注意转义反斜杠：`"$\\frac{1}{2}$"`（JSON 里 `\\` 表示一个字面反斜杠）
- 分隔符不成对时（例如正文里单独一个美元符号）按普通文本显示，不会报错
- 公式解析失败时显示原始 LaTeX 源码，不影响继续答题
- 用 AI 判分 / AI 解析时，模型也会用 LaTeX 输出数学式，界面同样会渲染

### 常见错误对照

| 界面现象 | 真实原因 |
| --- | --- |
| 题目变成「展示答案」+ 自判对错 | `type` 拼错了（如 `single`、`radio`、`single-choice`），被静默当成 `fill_blank` |
| 多选只选一个就判对 | `correctAnswer` 里只放了一个元素，漏了其它正确答案 |
| 保存后文件里的答案被改成了数组 | 正常现象：App 统一按数组形态写回 |
| 原来的 `id`（如 `Q001`）变成了 `q_a1b2…` 这样的长字符串 | 正常现象：App 给每题生成稳定随机 id，错题本靠它去重，不再依赖文件位置 |
| 显示「图片不存在：xxx.jpg」 | 图片没和 JSON 放同一目录，或文件名拼错、大小写不符 |
| 整个题库打不开 | JSON 语法错误，常见于多余/缺失的逗号、中文引号、末尾多写了逗号 |
| 列表里找不到这个题库 | 目录没添加，或 JSON 放在了第二层以下的子目录里（只递归一层） |
| 答完后没有解析框 | `analysis` 为空或省略了——空解析不显示框 |
| 数学式没渲染，显示成 $x^2$ 原样文字 | 分隔符不配对（如漏了结尾的 `$`），或写成了中文全角符号 |

### 编辑时的三个注意点

- **必须存成 UTF-8**，否则中文会乱码；用 VS Code 编辑会实时提示语法错误
- **只能用英文引号 `"`**，中文引号 `"` `"` 会让 JSON 解析失败
- **App 保存时会重写整个文件**：顶层除 `questions` 之外的字段（如你自己加的 `"title"`、`"author"`）会丢失，缩进也会统一成 2 个空格
- **`id` 会被替换**：App 启动时（以及添加题库目录时）会把非 `q_` 前缀的 id 换成随机长字符串写回文件，进入「错题本」页时再兜底检查；之后原样保留，请不要再依赖手写的 `Q001` 做外部引用

## 隐私

- **默认离线**：不配置 AI 时，App 不产生任何网络请求
- **AI 请求只发往 DeepSeek**：仅在你配置了 Key 并使用判分/解析时，把当前题目、标准答案和你的作答发到 `https://api.deepseek.com`，不经过任何中转
- **不收集数据**：没有统计、没有崩溃上报、没有广告 SDK
- **不申请任何存储权限**：题库读写通过 SAF 完成，只能访问你手动授权的文件夹
- **唯一的网络权限是 `INTERNET`**：普通权限，安装时不弹窗，仅供 AI 功能访问 DeepSeek
- **密钥存储**：以 base64 编码保存在 App 私有目录的 `config.json`——base64 只是编码不是加密，能读到该文件的人可以还原出明文

## 常见问题

**扫描不到题库？**
检查三点：目录是否已经添加；该目录的访问授权是否还在（失效就删掉重新添加一次）；JSON 是否放在了第二层以下的子目录里——App 只递归一层，更深层不会自动出现。

**统计没有写回原文件？**
答题过程中先写 App 文档目录下的工作副本（400ms 合并写），做完整套题、App 进入后台、离开练习页时再回拷原文件。回拷失败会在副本旁留一个 `.dirty` 标记，下次打开题库先补回拷；仍然失败就直接读副本，不会把最新统计冲掉。

**同名题库冲突？**
不会。工作副本按题库来源哈希隔离在 `文档目录/banks/<哈希>/` 下，不同目录里的同名 `.json` 各用各的副本。

**换手机怎么迁移？**
把题库文件夹整体拷过去，在新设备上重新添加目录即可，统计就在 JSON 里。

**点错题库了？**
在「题库管理」里点另一个题库即可切换，当前进度不会丢。练习进度会按题库保存，退出或重启 App 后重新打开同一题库会停在上次那一题（题库题目增删、改顺序后自动放弃旧进度，从头开始）。

**AI 判分 / 解析没反应？**
先到「我的 → 设置」确认状态显示「已配置」。再按错误提示判断：**401** 是 Key 无效或已被吊销，**402** 是账户余额不足，**429** 是请求过于频繁。填空题判分失败会自动退回手动自判，不影响继续做题。

## 已知限制

- 只递归**一层**子目录，且跳过 `.` 开头的隐藏目录；第二层以下的文件不会自动出现
- 普通题库的配图始终从题库源目录读取，**不会**随 JSON 复制到 App 私有目录；源目录被删或改名后图片会失效（错题本例外：收集时会把配图一起复制一份）
- 配图高度上限 320px，超长截图会被缩小
- 首页背景图已压缩为 WebP（约 2.8 MB），安装包体积主要来自 Flutter 引擎
- 填空/简答的自动判分**依赖 DeepSeek API**：没配置 Key 或网络不可用时只能手动自判；AI 判分是模型打分，同一答案偶尔可能出现分数波动
- 作答图片单次最多 **4 张**、单张上限 **5 MB**、合计上限 **10 MB**，图片会先压缩到长边 1600px；上传越多，token 消耗越高
- AI 解析每次都会重新请求，不会缓存；standard 插件在答完题或展示答案后都可使用，解析 Prompt 由插件自己生成
- AI 变式出题在归纳知识点时最多均匀采样原题库的 **60 道题**（题目再多也只取样本），并截断过长的解析文本，避免提示词超出上下文；生成结果按提交时的知识点出题，因此超大题库的变式题可能覆盖不到未采样到的题目
- 变式出题按希腊字母自动取下一个未占用的文件名（alpha…omega，用完后接 `-alpha-2` 等序号），不会覆盖已有题库；新题不携带原题配图
