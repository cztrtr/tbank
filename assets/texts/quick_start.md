# 快速开始

## 1. 每日打卡

- 打开 App 停在「首页」，点击中间的「打卡」卡片即可。
- 每天打卡一次，连续打卡天数会自动累计；断签后重新从 1 天开始。

## 2. 添加题库

- 一本题库就是一个 `.json` 文件，放在手机上任意文件夹里就行（比如在「文件管理」里新建一个「题库」文件夹）。
- 题库文件在电脑上的话，用数据线、网盘或聊天软件传到手机，再放进那个文件夹。
- 打开 App，点底部「管理」，再点右上角的「+」。
- 在系统弹出的文件夹选择器里，选中存放题库的文件夹，点「允许」。
- 文件夹里的 `.json` 题库会立刻显示在列表中，可以一次添加多个文件夹。
- 如果题目带配图，把图片和题库 `.json` 放在同一个文件夹里就行。

## 3. 开始作答

- 在「管理」页点题库名字，就进入练习。
- 单选、多选、判断：选好选项后点「提交」。
- 填空、名词解释、解答、证明：输入文字作答；也可以拍照上传手写作答。
- 提交后立刻看到对错和答案解析；选择题答完还能点「AI 解析」，让 AI 讲清楚每个选项。

## 4. 错题本

- 进入「我的」→「错题本」，App 会自动把所有答错过的题收集到一起。
- 错题按题库文件夹分组，每本最多 25 题。
- 同一道错题答对一次减 1 分、答错加 1 分，减到 0 就算完成；也可以手动删除某一本。
- **重要提示：删除之后，除非重置错题本，否则已有错题不会重新显示到错题本界面**

## 5. 配置 DeepSeek API

- 进入「我的」→「设置」，把 DeepSeek 的 API Key 粘贴到输入框，点「保存」。
- 配好之后，AI 判分、AI 解析、AI 出题才会工作；不配置也能正常刷题和看解析。
- **重要提示：不要将你的API Key泄露给任何人**

## 6. AI 出题

- 「我的」→「AI 出题」：输入主题和出题要求，勾选题型与数量，让 AI 造一套新题。
- 也可以回到「管理」，点题库右侧的星星按钮：AI 会读这份题库的知识点，重新出一套变式题。
- 生成的题目会保存到题库所在的文件夹，名字按希腊字母递增（alpha、beta、gamma…），不会覆盖已有题库。
