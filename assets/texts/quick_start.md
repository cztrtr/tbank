# 快速开始

## 1. 每日打卡

- 打开 App 停在「首页」，点击中间的「打卡」卡片即可。
- 每天打卡一次，连续打卡天数会自动累计；断签后重新从 1 天开始。

## 2. 添加题库

- 一本题库就是一个 `.json` 文件，放在手机上任意文件夹里就行（比如在「文件管理」里新建一个「题库」文件夹）。
- 题库文件在电脑上的话，用数据线、网盘或聊天软件传到手机，再放进那个文件夹。
- 打开 App，点底部「管理」，再点右上角的「+」。
- 在系统弹出的文件夹选择器里，选中存放题库的文件夹，点「允许」。
- 文件夹里的 `.json` 题库会立刻显示在列表中，可以一次添加多个文件夹。
- 如果题目带配图，把图片和题库 `.json` 放在同一个文件夹里就行。

## 3. 安装插件

- 内置的 `standard` 插件支持单选、多选、判断、填空/简答，普通题库默认用它打开，不需要安装。
- 如果题库根节点写了别的插件，比如 `"plugin": "coding"`，就要先装对应插件。
- 内置 `standard` 也可以用更高版本的 zip 热更新，更新后不需要重装 App。
- 进入「我的」→「设置」→「插件管理」：
  - 右上角文件夹按钮：导入本地 `.zip` 插件；
  - 右上角云朵按钮：填下载地址，从网络安装；
  - 内置插件不可卸载，第三方插件可以卸载。
- 插件右侧的齿轮可以打开它自己的配置页；配置只保存在这个插件目录里。

## 4. 开始作答

- 在「管理」页点题库名字，就进入练习。
- 单选、多选、判断：选好选项后点「提交」。
- 填空、名词解释、解答、证明：输入文字作答；也可以拍照上传手写作答。
- 第三方插件题型由插件自己渲染；答题按钮、解析位置以插件页面为准。
- 提交后立刻看到对错和题库自带解析；答完还可以点「AI 解析」，让 AI 讲清楚思路。

## 5. 错题本

- 进入「我的」→「错题本」，App 会自动把所有答错过的题收集到一起。
- 错题按题库文件夹分组，每本最多 25 题。
- 同一道错题答对一次减 1 分、答错加 1 分，减到 0 就算完成；也可以手动删除某一本。
- **重要提示：删除之后，除非重置错题本，否则已有错题不会重新显示到错题本界面**

## 6. 配置 DeepSeek API

- 进入「我的」→「设置」，把 DeepSeek 的 API Key 粘贴到输入框，点「保存」。
- 配好之后，AI 判分、AI 解析、AI 出题才会工作；不配置也能正常刷题和看解析。
- **重要提示：不要将你的 API Key 泄露给任何人**

## 7. AI 出题

- 「我的」→「AI 出题」：先选择出题插件，再勾选该插件支持的题型，输入主题、要求和数量。
- 生成时会按题型保证覆盖；某类题不够会先重试，全部题型都生成成功后才保存。
- 保存位置是 App 私有目录的 `Question/<主题>/`，会自动出现在「管理」页。
- 也可以回到「管理」，点题库右侧的星星按钮：AI 会读这份题库的知识点，按原题库所属插件重新出变式题。
- 「我的」→「拍书出题」可以拍教材题目或知识点讲解，再按插件题型生成新题。

## 8. 更新

- 在「设置 → 应用更新」里填更新发布地址，然后耐心等待。
